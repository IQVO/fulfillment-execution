The READ-ONLY analytical surface of the fulfillment-execution "Throughput & Lease-Health" data product (ADR-0012), served by the separate `cmd/fulfillment-reports` binary over a read-only pool (`default_transaction_read_only=on`) against the analytical database. It is NOT served by the OLTP `cmd/execution` binary documented in apis/openapi.yaml.

The report is a projection over this service's own domain events (TaskClaimed, TaskCompleted, LeaseExpired, WeightDiscrepancyDetected, PackageManifested), delivered on the `warehouse.fulfillment.analytics` topic and applied by `cmd/fulfillment-projector`, the single writer. It is therefore EVENTUALLY CONSISTENT: GET /reports/throughput/freshness tells how far the read model trails the event stream.

Rows are bucketed by UTC HOUR. There is no identity layer (ADR-0022).
