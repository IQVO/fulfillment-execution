The Station aggregate: a work position with a capability set, occupied by at most one worker/robot at a time. Covers registration (which also serves as idempotent re-certification), check-in/ check-out of the occupant (see [ADR-0014](/docs/adr/0014-labor-performance-integration-hooks)), and is the entry point for PULL dispatch (`task-claims` is a Station action).
