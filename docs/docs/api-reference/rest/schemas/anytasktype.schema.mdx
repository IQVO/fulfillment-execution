Every task type a task can have and a station can claim: the creatable TaskType values plus `RELOCATE` (a slot-plan move, ADR-0047) and `REPLENISH` (a pick-face replenishment, ADR-0050). RELOCATE and REPLENISH tasks are created only from WorkReleased on their process paths, never through `POST /tasks`, because they need the planned move.
