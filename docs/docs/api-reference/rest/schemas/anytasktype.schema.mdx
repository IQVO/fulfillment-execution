Every task type a task can have and a station can claim: the creatable TaskType values plus `RELOCATE` (a slot-plan move, ADR-0047), `REPLENISH` (a pick-face replenishment, ADR-0050) and `BREAK_CASE` (open a sealed case into loose eaches, ADR-0054, claimable since ADR-0055). RELOCATE, REPLENISH and BREAK_CASE tasks are created only from WorkReleased on their process paths, never through `POST /tasks`, because they need the planned move or break. A claimed BREAK_CASE task completes only through `POST /tasks/{id}/break-case`.
