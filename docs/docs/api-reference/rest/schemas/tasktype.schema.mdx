The process path a task belongs to. REBIN tasks are not creatable through `POST /tasks` by HTTP-only callers in practice — they arrive via the WorkReleased Kafka event's rebin path (see the process-path catalogue) — but they exist in the task store and therefore appear in read-model responses alongside PICK/PACK/SLAM.
